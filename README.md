# 📸 Instagram Downloader Chrome Extension

**Instagram Downloader** — это мощное и легковесное расширение для Google Chrome, позволяющее скачивать медиа-контент из Instagram в один клик.

![License](https://img.shields.io/badge/license-MIT-green)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?logo=typescript&logoColor=white)
![Chrome](https://img.shields.io/badge/Chrome-Extension-4285F4?logo=google-chrome&logoColor=white)

---

## ✨ Основные функции

* 📸 **Скачивание фото** из ленты и постов.
* 🎥 **Скачивание видео** из ленты.
* 📱 **Поддержка Reels и Stories**.
* 🛡️ **Приватность**: Работает полностью в браузере (Client-side), без использования сторонних серверов или сервисов.

## 🚀 Установка и запуск

### 1. Клонирование репозитория
Откройте терминал и выполните команду:
```bash
git clone [https://github.com/IvanYakunkin/instagram-downloader.git](https://github.com/IvanYakunkin/instagram-downloader.git)
cd instagram-downloader

```

### 2. Сборка проекта

Перед установкой в браузер необходимо собрать проект (установить зависимости и выполнить билд):

```bash
npm install
npm run build

```

*(Убедитесь, что в папке проекта появилась директория `dist`)*.

### 3. Загрузка в Chrome

1. Откройте Google Chrome и перейдите по адресу: `chrome://extensions/`
2. В правом верхнем углу включите тумблер **"Режим разработчика" (Developer mode)**.
3. Нажмите кнопку **"Загрузить распакованное расширение" (Load unpacked)**.
4. Выберите папку `dist`, созданную на этапе сборки.

✅ **Готово! Расширение активно.**

## 🛠 Техническое описание (How it works)

### 🔍 Обнаружение контента

Расширение использует `MutationObserver` для двух целей:

1. Мониторинг основного контейнера страницы.
2. Детект динамически подгружаемых постов при скролле ленты.
Это позволяет добавлять кнопки скачивания на лету без перезагрузки страницы.

### 🧠 Логика работы с медиа

#### Фотографии

Instagram хранит прямые ссылки на изображения, поэтому их скачивание происходит стандартным методом.

#### Видео и Аудио (Сложности и решения)

С видеоконтентом ситуация сложнее. Instagram использует технологию сегментированной загрузки:

* В качестве `src` видео-элемента выступает `blob-url` (ссылка на `MediaSource`), к которому нет прямого доступа.
* Видео и аудио потоки загружаются **раздельно** (Dash/HLS).
* По умолчанию браузер не может "склеить" эти потоки в один файл при скачивании.

**Текущая реализация (Метод перехвата):**
В расширении реализован метод инъекции скрипта (`inject script`), который перехватывает и модифицирует нативные методы браузера:

* `window.fetch()`
* `new MediaSource()`
* `URL.createObjectURL()`

Скрипт формирует карту соответствия между `blob-ссылкой` и реальными сетевыми адресами видео- и аудио-сегментов.

> **Важно:** Изначально ссылки указывают на сегменты (параметры `url &bytestart` и `&byteend`), но если убрать эти параметры, сервер Instagram отдает полный файл потока.

**Проблема склейки:**
Так как потоки разделены, для получения полноценного видео со звуком требуется либо использование `ffmpeg.wasm` на клиенте (ресурсоемко), либо отправка ссылок на внешний сервер для склейки. В текущей версии реализовано скачивание потоков по отдельности.

### 🔮 Планы по развитию (Roadmap)

Планируется добафить функционал, который позволит скачивать видео одним файлом без необходимости склейки.

**Суть метода:**

1. Перехват `media_id` (pk) из XHR запросов.
2. Отправка GET-запроса к внутреннему API Instagram: `/api/v1/media/{media_id}/info/`.
3. Получение прямой ссылки на исходное видео (со звуком) из JSON-ответа.
